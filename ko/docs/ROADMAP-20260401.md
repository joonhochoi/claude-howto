# 로드맵: claude-howto 2026–2027

> 2026년 4월 – 2027년 3월 · 이중 계층 지식 베이스 | 전체 계획: `TASKS-20260401.md`

---

## 비전

claude-howto를 정적인 튜토리얼 저장소에서 **살아 있는, 두 종류 독자를 겨냥한 지식 시스템**으로 전환합니다.

- **사람을 위해** — 난이도를 점진적으로 올리는 인터랙티브 시나리오 학습, 의사결정 트리, 전문가가 즐겨찾기에 넣을 만한 이름 붙은 패턴
- **AI 에이전트를 위해** — 에이전트가 Claude Code 작업을 수행하기 전에 조회하는 구조화된 메타데이터 인덱스. 이 저장소를 단순 콘텐츠가 아니라 인프라로 만듭니다

AI 에이전트를 1차 독자로 삼는 경쟁자는 없습니다. 이것이 우리의 해자입니다.

## 마일스톤

### M1 — 인프라 가동 · 2026년 4월 말

**출시 항목:**
- `scripts/quickstart.sh` — 신규 사용자를 위한 원 명령 설정(멱등)
- `QUICKSTART.md` — "첫 15분" 시각 가이드
- 10개 모듈 전체에 난이도 배지 + "무엇을 만들게 되는지" 미리보기
- `WHATS-NEW.md` + 모든 모듈의 버전 배지
- `.github/workflows/staleness-check.yml` — 모듈이 30일 넘게 검증되지 않으면 매주 월요일 이슈 생성
- 루트 `CLAUDE.md` — 프로젝트 자체 설정을 모범 사례 예시로 제공
- `scripts/build-agent-index.py` — 10개 모듈 전체를 읽어 `agent-manifest.json` + `AGENT-INDEX.md`를 출력하는 생성기
- **06-hooks** — 전체 심화 작업: 완성된 훅 스크립트 5개, 의사결정 트리, Try It Now, 패턴
- **08-checkpoints** — 전체 심화 작업: 311 → 800줄 이상, 워크플로 템플릿 3개, 의사결정 트리, 패턴

**여기서 시작하는 이유:** 인프라는 이후 모든 단계에 이득을 줍니다. 훅과 체크포인트는 가장 약한 모듈이며 신규 방문자를 잃을 가능성이 가장 큽니다.
